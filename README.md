# Tic Tac Toe

A simple Tic Tac Toe game developed using HTML, CSS, and JavaScript. Two players can play alternately, and the game automatically detects winners and draw situations.

## Features
- Two-player gameplay
- Winner detection
- Draw game detection
- Reset game functionality
- New game option

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- index.html
- style.css
- script.js

## Future Improvements
- Single-player mode with AI
- Score tracking
- Responsive design
